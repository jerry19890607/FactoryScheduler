# FactoryScheduler 管理員指南（Leader Guide）

> 對象：負責排程的 Leader。你載入當天資料、檢視與調整各機台時序、匯出結果。

---

## 1. 開啟程式

- **Windows**：雙擊 `FactoryScheduler_管理員.exe`（或 `FactoryScheduler.exe` → 選「管理員」）。
- 開啟後標題為「FactoryScheduler — 管理員 (Leader)｜每機台時序」。

---

## 2. 基本流程（由左而右的工具列按鈕）

1. **1. 載入主檔** → 選 `Schema/Factory_Scheduling_Schema_V4_3.2.xlsx`（機台能力、交期、產品轉譯）。
2. **2. 載入訂單** → 可**一次多選** `Orders/` 下的 Legacy 與 APS 檔。載入後會**自動排程**。
3. **＋ 載入抽件**（可選）→ 選 `Pulls/` 下的抽件檔；套用後自動重排。
4. 檢視中央的**每機台時序樹**；需要時調整後按 **重新排程**。
5. **匯出介面格式** → 產生每機台一分頁的 Excel（可交付 / 列印）。

> 抽件檔會持續疊加，系統會用 `ID + FILE_NAME` 自動略過已匯入過的，不會重複計算。

---

## 3. 看懂時序樹

每個機台是一個可展開/收合的節點，底下依**順序**列出該機台要做的工單：

| 欄位 | 意義 |
|---|---|
| 順序/機台 | 該機台的第幾個做 |
| PACKAGE_ID | 工單（整包，不可拆分） |
| 客戶 / 卡量 | 客戶、整包片數 |
| EMER_1 / EMER_2 / Std | 各急迫等級的抽件張數（有抽件才顯示） |
| 開始 / 結束 | 排定的實際時間（已避開停機時段） |
| 狀態 | 未處理 / 處理中 / 已完成 |
| 優先 | ★ 表示已設為優先或含抽件 |
| 鎖定 | 🔒 表示重排時固定不動 |
| 逾期(分) | 超過最晚完成的分鐘數 |

**顏色**：橘＝有抽件/優先、黃＝處理中、綠＝已完成、紅＝逾期。

---

## 4. 調整工單（選取 → 按鈕 → 重新排程）

先在樹上**選取一列或多列**（可按住 Ctrl/Shift 多選），再用下方按鈕：

- **設為優先 / 取消優先**：優先的工單會被優先排、往前靠。
- **鎖定 / 解鎖**：🔒 鎖定後，重排時固定在目前機台與位置不動。
- **標記處理中 / 標記已完成**：手動設定狀態。

> 調整完要按 **重新排程** 才會套用。
> **已設為「處理中」「已完成」或「鎖定」的工單，重排時會凍結在原機台**，不會被移走——
> 這樣插急件或重排時，不會打亂現場正在做的工單。

---

## 5. 與操作員連動

- 操作員在現場掃碼標「處理中 / 已完成」後，你的畫面**每 5 秒自動更新**狀態與顏色（不會動到你的捲動、選取、展開）。
- 你和操作員共用同一份狀態（同機 `factory_state.db`）。

---

## 6. 小技巧 / 注意

- 收合不需要關注的機台，畫面更清爽；自動更新**不會**把你收合的攤開、也不會清掉選取或跳回頂端。
- 任何「優先/鎖定/狀態」變更，記得按 **重新排程** 生效。
- 若摘要顯示「未分配」，代表該工單沒有合格機台（模組/群組對不上），需回頭檢查主檔或產品設定。
- 重新開啟程式需**再載入一次主檔/訂單**；但先前的狀態/優先/鎖定會記住並在重排時自動套用。
