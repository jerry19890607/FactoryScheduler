# FactoryScheduler 操作員指南（Operator Guide）

> 對象：現場操作員。你用掃描槍掃工單條碼，回報「處理中 / 已完成」。

---

## 1. 開啟程式

- **Windows**：雙擊 `FactoryScheduler_操作員.exe`（或 `FactoryScheduler.exe` → 選「操作員」）。
- 開啟後標題為「FactoryScheduler — 操作員｜掃描回報」。
- （選填）在最上方輸入**操作員編號**，之後的回報會記錄是誰做的。

> 若掃不到任何工單，表示 Leader 還沒載入當天工單並排程，請先請 Leader 處理。

---

## 2. 掃描工單

1. 用滑鼠點一下中間的**掃描框**（大字輸入框），讓游標停在裡面。
2. 用掃描槍掃條碼（等同鍵盤輸入 + Enter）。
3. 系統會**自動轉換**條碼取出工單碼，例如：
   - `W_271B4A-1` → `271B4A`
   - 本來就是純碼 `3783C4` → 直接用 `3783C4`
4. 掃到的工單會**加進下方清單**（預設已勾選）。可以**連續掃多張**累積起來。
5. 掃描框上方會顯示結果：
   - ✓ 綠字：成功帶出幾包
   - ✗ 紅字：查無工單（確認是否掃錯、或 Leader 尚未排入）

---

## 3. 回報狀態（可一次多筆）

下方清單每列前有勾選框，狀態欄顯示目前狀態。確認要回報的列有打勾後：

- 按 **標記勾選為處理中**（黃色）：開始製作時回報，該工單會在重排時固定在你的機台不被移走。
- 按 **標記勾選為已完成**（綠色）：做完時回報。

輔助按鈕：
- **全部勾選 / 全部取消**：快速切換清單勾選。
- **清空清單**：清掉目前累積的掃描清單（不影響已回報的狀態）。

回報後該列狀態會更新並變色（處理中黃、已完成綠），同時同步給 Leader 的畫面。

---

## 4. 典型作業順序

1. 要開工：掃該工單條碼 → 確認出現在清單 → 按「標記勾選為處理中」。
2. 做完：再掃一次（或從清單勾選）→ 按「標記勾選為已完成」。
3. 多張一起完成：連續掃多張 → 全部勾選 → 一次「標記勾選為已完成」。

---

## 5. 常見問題

| 狀況 | 處理 |
|---|---|
| 掃了顯示「查無工單」 | 確認條碼正確；若仍無，請 Leader 確認該工單已載入並排程。 |
| 掃同一包的不同工單號 | 系統會對應回同一個整包（PACKAGE_ID），屬正常。 |
| 不小心加錯到清單 | 按「清空清單」重來，或取消該列勾選後再回報；清單只是暫存，不影響已回報狀態。 |
| 沒有「處理中」只想標完成 | 直接勾選後按「標記勾選為已完成」即可。 |
